# Índice de experimentos

Esta carpeta conserva el desarrollo experimental del proyecto. La numeración original se mantiene para que los resultados del informe y de Comet puedan relacionarse con el código que los produjo.

- `1` a `7`: comprensión del problema, exploración, primeros preprocesamientos y modelos base.
- `10` a `17`: nuevos pipelines, modelos por cantidad de jets, ensambles y validación cruzada.
- `20`: búsqueda y evaluación adicional de XGBoost sobre variables de árboles.
- `50` a `59`: reconstrucción ordenada del pipeline, baselines, validación y ajuste de XGBoost.
- `60` a `62`: comparación de métodos completos y preparación del pipeline público final.

Los notebooks y scripts de esta carpeta documentan iteraciones y no representan necesariamente la solución seleccionada. Para ejecutar la versión final, consultar [`../entrega/`](../entrega/).
